# matlab-lib-public

Small MATLAB scripts for data and image analysis. Each folder contains one script with its own README.

| Folder | Description |
|---|---|
| [msd-random-walk](msd-random-walk) | 2D random walk simulation, MSD with errors, fit of the diffusion coefficient |

## Usage

Open a folder in MATLAB and run its script. Figures are saved in that folder's `figures/` subfolder.
